MorWatch v1.0 — PWA
====================
קבצים: index.html, style.css, app.js, sw.js, manifest.webmanifest, icons/

פרסום:
1. העלה את כל תוכן התיקייה לאחסון סטטי עם HTTPS (למשל GitHub Pages או Netlify).
2. פתח את כתובת האתר באייפון באמצעות Safari.
3. לחץ שיתוף > הוסף למסך הבית (Add to Home Screen).
4. לאחר ביקור ראשון וטעינת קובצי האפליקציה, היא תוכל לפעול גם ללא אינטרנט.

בדיקה מקומית במחשב:
בתוך התיקייה הרץ: python -m http.server 8000
פתח http://localhost:8000 בדפדפן.

הערות:
- צליל הסיום עשוי להיות תלוי במדיניות השמע של המכשיר ובמצב השתקה.
- iOS אינו מבטיח הפעלת JavaScript והתראות כאשר PWA ברקע או כשהמסך נעול.
- טיימר לשעת יעד: אם היעד כבר עבר (או שווה לשעה הנוכחית), היעד יהיה מחר.
- השהיית טיימר לשעת יעד מקפיאה את הזמן שנותר, כך שהיעד בפועל נדחה.
- משך זמן בגלגלת: 00:00 עד 99:59.
- נתוני חישובים לא נשמרים בין הפעלות.
